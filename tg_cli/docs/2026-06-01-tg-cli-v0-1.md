# tg-cli v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a safe `tg-cli` command for the Telegram group-chat game, covering account inspection, group discovery, safe sends, message history, live observation, and external-agent-assisted reply context.

**Architecture:** Add a standalone `tg_cli` package beside Telethon. The CLI uses async Telethon calls through a thin adapter, with every write operation going through a safety layer for chat whitelisting, pause state, confirmation, dry-run, and audit logging.

**Tech Stack:** Python standard library `argparse`, `asyncio`, `json`, local Telethon source, pytest for unit tests.

---

### Scope Decisions

- Command name: `tg-cli`.
- Default session path for local use: `/Users/bytedance/ai-demo/OhMyTelethon/printer.session`.
- Test whitelist chat: `5217114569` (`lu 和 王哥`, two-person group).
- AI drafting: Codex, Claude, or another external agent remains outside the CLI for v0.1. `game suggest` emits an agent-ready context bundle; the operator decides the reply and sends through `tg-cli send`.
- One-minute live play is handled by `game round`: the CLI listens for new inbound messages, prompts the current operator for a reply, sends through the safety layer, and stops at duration or max-reply limits.
- Auto mode and daemon mode are intentionally out of scope for v0.1.

### Acceptance Criteria

- `tg-cli me` shows the current account without printing credentials.
- `tg-cli groups` lists the two-person test group.
- `tg-cli history 5217114569 --limit 5` prints recent messages.
- `tg-cli send 5217114569 "..." --yes` sends only if the chat is whitelisted.
- Sending to a non-whitelisted chat fails before calling Telethon send.
- `tg-cli pause` blocks all write operations until `tg-cli resume`.
- Audit logs do not contain raw message text, API hash, phone number, or session bytes.
- `tg-cli game suggest 5217114569` emits recent context and profile guidance for an external agent, but does not send.
- `tg-cli game round 5217114569 --duration 60 --max-replies 8` runs a bounded live session and exits automatically.
